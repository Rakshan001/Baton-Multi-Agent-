# Team Sync review register (2026-09-29)

This register covers four independent reviews of Team Sync v1 and the team specs:
- a security review
- a correctness and edge-case review
- prior-art and RBAC web research
- a code grounding check

Every finding maps to where v2 ([README.md](README.md)) resolves it. The status is
**Resolved-in-design** unless marked otherwise. Nothing has been implemented yet.

## Prior art that changed the design

- **Docket** dropped P2P because claims are only advisory, so §7.6 treats claims as advisory by design.
- **p2panda** strong removal and graded permissions led to §5.
- **Hypercore** fork counter led to §9.
- **SSB** fork proofs led to §9.
- **Keyhive** encrypt-on-removal led to §13.3 phase 2.
- **Anytype**'s ACL needs online consensus nodes. That is the anti-pattern we avoid (§5.4 recovery mode instead).

2. **Custodian model:** 2 custodian devices, or 1 custodian device plus a paper recovery key?

4. **Apple Developer ID** for Keychain access groups, notifications, Local Network and a signed .dmg. It is required for §4.1 and §12.
